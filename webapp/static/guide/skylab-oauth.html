Skylab OAuth Setup Guide

Configure OAuth for the Org Chart API Tester against Workday Skylab.

Skylab Live mode uses a Bearer access token only. User identity is encoded in the token — the Username field is not used.

Path 1 — Generate credentials yourself (recommended)

Step 1 — Register an API Client (one-time)

In the Skylab performance tenant:

  1. Open Register API Client for Integrations (2997$5931).
  2. Create a client (e.g. Org Chart API Tester).
  3. Enable scope Organizations and Roles (required for orgchart).
  4. Token user must have domain Reports: Navigate Organization.
  5. Save Client ID and Client Secret (secret shown only once).

Step 2 — Generate a refresh token

  1. On the API Client, open Manage Refresh Tokens.
  2. Select the user (wd-developer or superuser).
  3. Click Generate and copy the refresh token.
  4. Store securely — do not commit to git.

If you change scopes later, regenerate the refresh token.

Step 3 — Exchange refresh token → access token (curl)

export OC_OAUTH_CLIENT_ID='your-client-id'
export OC_OAUTH_CLIENT_SECRET='your-client-secret'
export REFRESH_TOKEN='your-refresh-token'

curl -sS -X POST 'https://org.skylab.inday.io/ccx/oauth2/performance/token' \
  -u "${OC_OAUTH_CLIENT_ID}:${OC_OAUTH_CLIENT_SECRET}" \
  -H 'Content-Type: application/x-www-form-urlencoded' \
  -d "grant_type=refresh_token" \
  -d "refresh_token=${REFRESH_TOKEN}" | python3 -m json.tool

Copy access_token from the response. Tokens expire (~1 hour).

Step 4 — Connect in the tester

  1. Mode: Live · Host: org.skylab.inday.io · Tenant: performance
  2. Password: Bearer <access_token> or paste raw JWT
  3. Click Connect

Step 5 — Use Get token (recommended)

  1. Set Live mode, Skylab host and performance tenant.
  2. Expand the OAuth panel.
  3. Enter Client ID, Client Secret, and Refresh Token.
  4. Click Get token — access token fills Password automatically.
  5. Click Connect.

Secrets are sent only to your local backend for the exchange; they are not saved to disk.

Path 3 — SUV without OAuth

Use a SUV (*.workdaysuv.com) in Live mode with username + password. ID token is obtained automatically. Not valid for official ORG-21922 Skylab sign-off.
